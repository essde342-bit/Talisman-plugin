# RustWeapons Client

Клиентский Fabric-мод для Minecraft Java 1.21.4. По умолчанию перезарядка назначена на R.

Требуется Fabric Loader, Fabric API и серверный плагин RustWeapons с поддержкой канала `rustweapons:reload`.

Установка: положить `RustWeaponsClient-1.0.0.jar` в папку `mods` клиента. На сервер мод ставить не нужно. Серверу нужен обновлённый `RustWeapons-1.0.0.jar`.
