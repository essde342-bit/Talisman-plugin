# Server Plugins — Paper 1.21.4

В этом репозитории находятся два независимых плагина для **Minecraft Paper 1.21.4**. Они собираются вместе одной командой, но устанавливаются отдельными JAR-файлами.

## 1. TalismanPlugin

Добавляет зачарованный тотем «Талисман Ярости». Пока он находится в левой руке, игрок получает:

| Характеристика | Изменение |
| --- | ---: |
| Урон атаки | +3 |
| Скорость атаки | +15% |
| Максимальное здоровье | -2 HP (одно сердечко) |

Команды:
- `/talisman` или `/talisman fury` — получить талисман.
- `/talisman give <игрок> fury` — выдать его другому игроку.

## 2. CombatSystem

Добавляет глобальное переключение PvP и защиту от выхода во время боя.

### Как работает бой

- Если PvP включено, любой успешный удар игрока по другому игроку активирует боевой режим у **обоих** участников.
- Это работает с любым оружием, рукой и снарядами, выпущенными игроком (например, стрелами и трезубцами).
- Над каждым участником появляется красная boss bar с обратным отсчётом от 30 секунд.
- Каждый новый удар обновляет таймер до 30 секунд.
- Когда таймер заканчивается, красная полоса исчезает и игрок может безопасно выйти.
- Если участник боя отключится раньше окончания таймера, его предметы из инвентаря, брони и второй руки выпадут на месте выхода; накопленный опыт также выпадет. Игрок будет убит.
- При выключении PvP текущие боевые таймеры снимаются.

### Команды

- `/pvp on` — включает PvP и боевую систему.
- `/pvp off` — отключает урон от других игроков и показывает всем зелёную boss bar «Пвп сейчас отключено».

Команда меняет глобальный режим сервера и доступна операторам (право `pvpsystem.admin`). Состояние сохраняется в `CombatSystem/config.yml` и переживает перезапуск сервера. PvP включено по умолчанию.

## Сборка

Нужны **JDK 21** и **Maven**. В корне репозитория выполни:

    mvn --batch-mode clean package

GitHub Actions автоматически собирает оба плагина после push в `main`. Для скачивания готовых JAR открой Actions и скачай артефакты `TalismanPlugin-1.0.0` и `CombatSystem-1.0.0`.

## Установка на сервер

1. Скачай оба JAR из последнего успешного запуска GitHub Actions (или только нужный плагин).
2. Помести выбранные JAR-файлы в папку `plugins` сервера Paper 1.21.4.
3. Перезапусти сервер.
4. Для CombatSystem используй `/pvp on` или `/pvp off` от имени оператора.

Каждый модуль формирует собственный JAR. Устанавливать оба плагина вместе необязательно.
