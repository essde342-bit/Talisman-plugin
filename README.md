# Server Plugins — Paper 1.21.4

В этом репозитории находятся шесть независимых плагинов для **Minecraft Paper 1.21.4**. Они собираются вместе одной командой, но устанавливаются отдельными JAR-файлами.

## 1. TalismanPlugin

Добавляет зачарованный тотем «Талисман Ярости». Пока он находится в левой руке, игрок получает:

| Характеристика | Изменение |
| --- | ---: |
| Урон атаки | +3 |
| Скорость атаки | +15% |
| Максимальное здоровье | -2 HP (одно сердечко) |

Команды: /talisman, /talisman fury, /talisman give <игрок> fury.

## 2. CombatSystem

Добавляет глобальное переключение PvP и защиту от выхода во время боя.

- При успешном ударе игрока по другому игроку у обоих активируется бой на 30 секунд.
- Над участниками появляется красная boss bar с обратным отсчётом.
- Новый удар обновляет таймер.
- Если участник выходит во время боя, его предметы и опыт выпадают на месте выхода.
- При выключении PvP боевые таймеры снимаются.
- Можно выдавать топор выделения и создавать зоны, в которых PvP отключено.

Команды: /pvp on и /pvp off; /pvpwand; /pvpzone create <имя>, /pvpzone delete <имя>, /pvpzone list. Команды доступны операторам (право pvpsystem.admin).

## 3. RTAccess

Добавляет специальные двери РТ, ключ-карты, защищённые блоки и приватные регионы.

- /rt give card <игрок> [количество] — выдать синюю ключ-карту.
- /rt give door <игрок> [количество] — выдать специальную дверь.
- /rt_block — пометить блок в руке: каждый поставленный блок этого типа будет защищён.
- Защищённые блоки нельзя ломать, взрывать, сдвигать поршнями или изменять жидкостями/сущностями.
- /rt_private — получить топор выделения привата.
- Внутри RT Private игроки в выживании и приключении не могут размещать блоки или жидкости; в креативе это разрешено.
- Дверь открывается синей ключ-картой на 5 минут.

## 4. CorpsePlugin

При смерти игрока на месте смерти появляется горизонтальное тело с никнеймом над ним.

- Нажми ПКМ по телу, чтобы открыть инвентарь на момент смерти.
- Лут общий: если несколько игроков открыли один труп, они видят одни и те же предметы.
- Предметы переносятся в труп, а не дублируются на земле.
- Вместо Armor Stand используется полноценная модель игрока с классическим широкоруким Стивом, лежащим горизонтально.
- На модели отображаются броня и предметы в руках, пока соответствующие вещи остаются в луте.
- Данные трупов и их содержимое сохраняются после перезапуска сервера.
- Для CorpsePlugin требуется отдельный серверный плагин PacketEvents 2.7.0.
- Стандартное время жизни трупа — 30 минут.

Команды (право corpse.admin):
- /corpses list — количество активных трупов.
- /corpses reload — перечитать настройки.
- /corpses clear — удалить все трупы.

## 5. CratePlugin

Добавляет таймерные крейты на основе обычных бочек.

- Посмотри на обычную бочку и введи /crate_create <название>. Бочка зарегистрируется как крейт.
- Над бочкой появится голограмма с названием и таймером до открытия.
- Пока таймер идёт, открыть бочку нельзя.
- Когда время заканчивается, в бочку помещается случайный лут, а она становится доступна игрокам.
- Каждый предмет проверяется независимо по своему шансу от 1 до 100 процентов.
- Настройки предметов и времени сохраняются после перезапуска сервера.
- Изменение времени в редакторе влияет на новые крейты; уже запущенные таймеры не сбрасываются.

Команды (право crate.admin):
- /crate editor — редактор предметов и шансов.
- /crate list — список созданных крейтов.
- /crate remove — удалить крейт, на бочку которого смотришь.
- /crate_create <название> — создать крейт на бочке, на которую смотришь.

В редакторе:
- Перенеси предмет на курсоре в пустой слот или используй SHIFT + ЛКМ по предмету в своём инвентаре, чтобы добавить его (начальный шанс — 100%).
- SHIFT + ЛКМ по предмету в редакторе — изменить шанс (1–100).
- ПКМ по предмету в редакторе — удалить его и вернуть в инвентарь.
- Нажми на часы, чтобы изменить время до открытия. Время вводится в секундах (от 1 до 604800).
- В бочку помещается до 27 записей лута. Размер стека предмета сохраняется из редактора.

## 6. RTMap

Добавляет минималистичную чёрную карту без текстур, рельефа и изображения местности.

- Белые значки обозначают сохранённые RT-точки.
- Синяя точка показывает ваше положение в центре карты.
- Направление взгляда и текущие координаты обновляются, пока карта открыта.
- При наведении на белую точку в подсказке отображаются название и координаты.
- Точки сохраняются по мирам и не пропадают после рестарта.
- По умолчанию карта показывает область в радиусе 1500 блоков вокруг игрока (настраивается в config.yml).

Команды:
- /rtmap — открыть карту.
- /rtmap_add <название> — добавить точку в текущем месте.
- /rtmap_remove <название> — удалить точку.
- /rtmap_list — показать все точки.
- /rtmap_reload — перезагрузить настройки и точки.

**Ограничение клиента:** эта версия открывает карту командой /rtmap. Обычный Paper-плагин не может сам перехватить произвольную клавишу G. Для открытия именно на G потребуется отдельный клиентский мод. В этой версии подсказка с координатами появляется при наведении на значок-точку в инвентаре.

## 7. RustWeapons

Добавляет Rust-подобное оружие с 2D-моделями, отдельным отображением предмета в GUI и в руке (через item-model display context в 1.21.4), hitscan-выстрелами, магазинами и перезарядкой.

Оружие: Semi-Automatic Rifle, Assault Rifle (AK), Thompson, Custom SMG, Pump Shotgun, Double Barrel, Bolt Action Rifle, M92.

- ПКМ — выстрел.
- /rw reload — перезарядить оружие в основной руке.
- /rw give <игрок> <semi|ak|thompson|smg|pump|double|bolt|m92> [кол-во] — выдать оружие.
- /rw ammo <игрок> <rifle|pistol|shell> [кол-во] — выдать патроны.
- /rw list — список оружия.

Боеприпасы:
- rifle — винтовочные 5.56 (Semi, AK, Bolt).
- pistol — пистолетные (Thompson, SMG, M92).
- shell — дробовые 12 калибра (Pump, Double Barrel).

Право для выдачи предметов: rustweapons.admin (по умолчанию OP).

Resource Pack находится в RustWeapons/resource-pack. В нём для каждого оружия настроено переключение между отдельной моделью GUI и отдельной моделью руки. Сейчас используются ванильные текстуры-заглушки, чтобы pack работал до добавления собственных PNG. Чтобы включить автоматическую отправку пака, укажи прямую HTTPS-ссылку в config.yml в resource-pack.url.

## Сборка

Нужны **JDK 21** и **Maven**. В корне репозитория выполни:

    mvn --batch-mode clean package

GitHub Actions собирает семь JAR:
- TalismanPlugin-1.0.0
- CombatSystem-1.0.0
- RTAccess-1.0.0
- CorpsePlugin-1.0.0
- CratePlugin-1.0.0
- RTMap-1.0.0\n- RustWeapons-1.0.0\n- RustWeapons-ResourcePack.zip

## Установка

1. Если используешь CorpsePlugin, установи PacketEvents 2.7.0 в папку plugins и перезапусти сервер.
2. Скачай нужные JAR из последнего успешного запуска GitHub Actions.
3. Помести выбранные файлы в папку plugins сервера Paper 1.21.4.
4. Перезапусти сервер.

Каждый модуль формирует собственный JAR. Устанавливать все плагины вместе необязательно.
