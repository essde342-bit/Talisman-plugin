# TalismanPlugin

Плагин для **Minecraft Paper 1.21.4**. Добавляет зачарованные тотемы, которые дают характеристики, пока находятся в левой руке.

## Сейчас доступен: Талисман Ярости

Предмет — зачарованный тотем бессмертия.

| Характеристика | Изменение |
| --- | ---: |
| Урон атаки | +3 |
| Скорость атаки | +15% |
| Максимальное здоровье | -2 HP (одно сердечко) |

Бонус урона добавляется к характеристике атаки игрока, поэтому работает вместе с уроном оружия в основной руке и зачарованиями вроде «Остроты». Скорость атаки увеличивается именно на 15% через множитель атрибута, а не на фиксированное число.

Все три модификатора привязаны к слоту OFFHAND. Эффекты включаются и выключаются самой системой атрибутов Minecraft при помещении тотема в левую руку или его извлечении. Периодические задачи и ручное изменение характеристик игрока не используются.

## Команды

- **/talisman** или **/talisman fury** — получить Талисман Ярости.
- **/talisman give <игрок> fury** — выдать талисман другому игроку (требуется право talisman.admin).

Право talisman.use по умолчанию доступно всем. talisman.admin по умолчанию есть у операторов.

## Сборка

Нужны JDK 21 и Maven.

В корне проекта выполни команду:

    mvn package

Готовый файл появится в target/TalismanPlugin-1.0.0.jar.

Также GitHub Actions автоматически собирает JAR после push и прикладывает его к запуску workflow как артефакт TalismanPlugin-1.0.0.

## Установка

1. Собери проект или скачай JAR из раздела Actions → последний успешный запуск → Artifacts.
2. Помести JAR в папку plugins сервера Paper 1.21.4.
3. Перезапусти сервер.
4. Выполни /talisman и возьми предмет в левую руку.

Компилируется против Paper API 1.21.4-R0.1-SNAPSHOT, Java 21.
